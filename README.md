# Blog Personal con Autenticación Básica

Este es un proyecto académico de una aplicación web tipo Blog. Permite publicar, editar y eliminar entradas, integrando una autenticación básica de usuarios.

## Tecnologías Usadas
- HTML5
- CSS3
- JavaScript (Vanilla)
- LocalStorage (Persistencia de datos)

## Funcionalidades
- Registro e Inicio de sesión.
- CRUD completo de publicaciones (Crear, Leer, Actualizar, Eliminar).
- Diseño responsivo.
